# 周计划

**把想过的一年，变成能行动的每一周。**

想做的事很多，却总被眼前任务打断？周计划把长期方向、本周重点和每天的行动放在同一个地方。先想清楚这一周，再从今天开始做。不需要复杂的项目管理流程，打开页面就能写。

![周计划门户页面](docs/portal-preview.png)

## 你可以这样规划

1. **写下长期方向。** 长期目标和便笺始终在旁边，不随周次切换，方便回看自己为什么而做。
2. **安排这一周。** 用学习、实践、工作三个区域写周目标；还没想好每天做什么时，可以在列表视图里连续规划多个星期。
3. **落实到每天。** 七天计划同屏可见。按 Enter 就能写下一项，完成后勾选；用文字颜色区分任务类型。
4. **回顾进展。** 为整周选择一次完成度，继续切换到下一周。输入自动保存，按自己的节奏前进。

周目标和日任务保留各自的书写空间，不要求为每项任务建立关联。整条日任务跨日期复制或剪切粘贴时，会保留颜色和完成状态。

## 适合谁

- 习惯以周为单位思考，希望一年 52 周的目标能连续推进的人。
- 想把学习、实践和工作分开规划，又希望每天做什么一眼可见的人。
- 喜欢直接输入文字，不想反复点击“新增任务”或维护复杂字段的人。
- 想把计划数据保存在自己电脑或自己的服务器上的人。

## 立即开始

需要 **Node.js 22.5 或更新版本**。项目没有第三方运行依赖。

可以[直接下载 ZIP](https://github.com/yueqi7255-box/weekly-planner/archive/refs/heads/main.zip)，或通过 Git 获取源码：

```bash
git clone https://github.com/yueqi7255-box/weekly-planner.git
cd weekly-planner
npm start
```

打开终端输出的本地地址，创建账号即可使用。默认从 `4173` 端口开始；如果端口被占用，会自动尝试后续端口。登录后进入 `/app` 工作台。

首次启动会创建 `data/planner.sqlite3`。每个账号的长期目标、便笺、周目标和日任务分别存储；可在页面右上角的「数据选项」中导出或导入当前账号的 JSON 数据。

## 自己部署

应用服务只监听 `127.0.0.1`。公网部署需要反向代理和 HTTPS；`deploy/` 提供 systemd、Nginx、每日 SQLite 快照与证书续期的配置示例。将示例域名、证书路径和数据目录改为自己的配置后再使用。

建议通过 `PLANNER_DB=/path/to/planner.sqlite3 npm start` 把运行中的数据库放在不参与云盘同步的目录。**服务器上的备份也应定期复制到另一台设备**；站内 JSON 导出可作为额外备份。本地和云端使用独立数据库，不会自动同步。

已有旧版单用户数据可使用 `scripts/bootstrap-legacy.js` 迁移。运行前先备份数据库并停止旧服务；该脚本从标准输入读取 `{"username":"planner","password":"..."}`，只迁移一次。

## 当前范围

- 桌面端提供周视图和连续周目标列表视图；移动端目前沿用周视图。
- 注册使用用户名和密码，无须邮箱；登录后可修改密码。当前没有邮件验证或自助找回密码功能。
- 数据保存在 SQLite。导入 JSON 会替换当前账号的数据，操作前页面会要求确认。

运行检查：

```bash
npm test
```

发现问题或有改进想法，欢迎在 [Issues](https://github.com/yueqi7255-box/weekly-planner/issues) 交流。
