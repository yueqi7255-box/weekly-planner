# 周计划

一个带注册和登录的周计划网站。每个账号拥有独立的长期目标、便笺、周目标和七天日计划。数据存储在 SQLite。

## 部署

Node 服务只监听 `127.0.0.1`，公网访问需要反向代理与 HTTPS。`deploy/` 提供 systemd 服务、Nginx 配置和每日 SQLite 快照示例；使用前将 `planner.example.com`、证书路径及数据目录替换为自己的配置。不要将生产数据库、密码或私钥提交到仓库。

不同部署各有独立数据库；在其中一个地址修改内容，不会自动同步到另一个地址。

## 启动

需要 Node.js 22.5 或更新版本。在本目录运行：

```bash
npm start
```

启动后打开终端打印的本机地址。默认从 `4173` 端口开始；若被占用，会自动尝试后续端口。如需指定端口，运行 `PORT=4180 npm start`。

首次启动会创建 `data/planner.sqlite3`。建议将 SQLite 数据库放在不参与云盘同步的本地目录，并通过 `PLANNER_DB=/path/to/planner.sqlite3 npm start` 指定。页面右上角的「数据选项」可以导出或导入当前账号的 JSON 备份。导入只会替换当前账号的数据，操作前有确认提示。

## 账号

- 注册使用用户名和密码，无须邮箱；用户名为 3–32 个字母、数字、下划线或连字符，密码至少 8 个字符。
- 登录后可在「数据选项」中修改密码或退出。会话有效期为 30 天；修改密码会使其他设备的会话失效。
- 当前不提供邮件验证或自助找回密码；遗失密码需要服务器管理员处理。
- 旧版单用户数据只由部署时的 `scripts/bootstrap-legacy.js` 迁移一次。该脚本从标准输入读取 `{"username":"planner","password":"..."}`，运行前必须先备份数据库并停止旧服务；原始旧表保留以便核查。

## 编辑

- 左侧长期目标与便笺可直接输入，内容不随周次切换。
- 每周学习、实践、工作各是一块连续多行文本区。按 Enter 新起一行。
- 桌面端顶部的两个图标可切换周视图与列表视图。列表连续展示各周的三类目标；每个分类仍是一块多行文本区，输入自动保存，滚动到边缘会继续加载周次。点击周次后，顶部原有周次切换会同步到该周。移动端暂时保持原周视图。
- 每个日期是一块连续任务编辑区。输入后按 Enter 创建下一项；删掉最后一个字时保留当前空行，再按一次退格或离开空行才删除该项。勾选框标记完成，任务右侧出现的颜色按钮可更改该行文字色。
- 复制或剪切整条任务，再粘贴到空任务行，会保留文字颜色和完成状态；复制部分文字仍按普通文本处理。普通多行文本粘贴后每行会成为一项任务。
- 修改会自动保存。切周前，页面会先等待当前修改写入数据库。顶部显示保存状态。

运行检查：

```bash
npm test
```

本地和云端都需要应用账号；公网部署请启用 HTTPS。
